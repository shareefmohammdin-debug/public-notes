# Public Notes — Frontend

Public Notes is a public note-sharing web application built with React.

The idea behind the project is simple:

> What if everyone had one shared notebook?

The application allows people to create and view public notes. A note can contain a title, author name, content, category, and an optional URL.

## Features

- View all public notes
- Filter notes by category
- View a single note
- Create a new note
- Add an author name
- Add an optional URL
- Share a note
- Delete a note
- Responsive user interface
- Client-side routing

## Categories

The application currently supports four categories:

- Notes
- Links
- Favorites
- Archive

## Technologies

- React
- JavaScript
- React Router
- HTML
- CSS
- Fetch API
